# Campaigns

Each campaign gets its own directory here.

## Directory Structure

```
campaigns/
  <campaign-slug>/
    brief.md      # Campaign brief written by Strategist
    okrs.md       # Objectives and Key Results
```

## Campaign Brief Format

The Strategist writes `brief.md` with these sections:
- Overview (goal, timeline, budget)
- Ideal Customer Profile
- Positioning statement
- Key messages (primary + proof points)
- Content plan (table of pieces with format, platform, angle, word count)
- KPIs (reach, engagement, clicks, conversions)
- Publish schedule

See `prompts/strategist.md` for the full brief template.

## Naming Conventions

Use kebab-case slugs: `linkedin-launch-q1`, `product-launch-v2`, `founder-story`
